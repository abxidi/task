# 接手 Agent 阅读检查

接手 Agent 在开始计划 01 前，应只依赖本仓库文档回答以下问题。答不出或答案与“预期”不同，说明交接内容未读完整或存在冲突，应停止编码。

| 问题 | 预期答案 | 依据 |
| --- | --- | --- |
| 两个优先级维度是什么？ | 横轴紧急度，纵轴重要度 | 设计规格 4.1 |
| 取值范围和组合数是什么？ | 两者均为整数 `-3...3`，共 49 个坐标 | 设计规格 4.1 |
| 任务点如何表达两个维度？ | 背景色表示紧急度，内部带符号数字表示重要度 | UI 规范 4.3 |
| 任一维度为 0 时属于哪个象限？ | 不属于四象限，归为“待判断” | 设计规格 4.1 |
| 新任务最少填写什么？ | 只需要标题；其他字段使用默认值 | 设计规格 5.1、5.2 |
| 任务编辑器首屏突出什么？ | 标题、描述和子任务 | UI 规范 6.1 |
| 四象限在设置中的位置？ | “任务设置”最上方，其他属性在后 | UI 规范 6.3 |
| 未配置 AI 时发生什么？ | 隐藏 AI 入口和面板，基础功能完整 | 设计规格 7.1 |
| AI 是否能直接修改任务？ | 不能；只能输出默认未选中的待审阅变更 | UI 规范 8.3、计划 04 |
| 数据存储在哪里？ | 当前 Mac 的 SwiftData，不提供账号或云同步 | 设计规格 1、9 |
| 看板完成列有什么约束？ | 每个项目恰好一个；进入/离开同步完成状态 | 设计规格 6.1 |
| 实施顺序是什么？ | 01 基础、02 核心任务、03 看板指标、04 AI 与发布 | 交接 README |
| 完成的最低证据是什么？ | 测试、release build、Task.app 打包和 codesign 验证 | `AGENTS.md` |

## 开工前自检命令

```bash
rg -n -- '-3|\+3|49 个' docs/superpowers/specs docs/ui AGENTS.md
rg -n 'AI 未配置|只保存在本机|任务设置' docs/superpowers/specs docs/ui
git status --short
```

不要使用 `-5...5`、11 级颜色或形状编码开始实现；这些是已经废弃的澄清过程，不是当前设计。
