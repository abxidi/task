# 新开发 Agent 启动提示

在指向本仓库的新 Agent 任务中发送以下内容：

```text
请开发这个仓库中的 Task 原生 macOS 应用。

开始前完整阅读根目录 AGENTS.md，并按其中顺序阅读产品规格、UI 规范、UI 参考、交接 README 和实施计划。不要重新设计产品，也不要使用临时 Web 技术替代 SwiftUI 原生应用。

从 docs/superpowers/plans/2026-07-13-task-macos-01-foundation.md 开始，严格按 checkbox 顺序执行。使用测试驱动开发：先写失败测试、确认失败、实现最小代码、确认通过，再提交。计划 01 完成门通过后再进入计划 02，然后依次完成计划 03 和 04。

不可变规则：紧急度和重要度均为整数 -3...3；四象限保持正方形；背景色表示紧急度，内部数字表示重要度；任务编辑首屏只突出标题、描述和子任务；AI 未配置时基础软件必须完整可用。

实现 UI 时打开 docs/ui/task-ui-reference.html 与 docs/ui/task-macos-ui-spec.md 对照。框架 API 按 docs/handoff/OFFICIAL_REFERENCES.md 重新核对当前官方文档。

当前任务先执行计划 01。不要只输出方案，直接实现、运行测试、打包 Task.app，并在计划 01 完成门处汇报：修改文件、测试结果、Task.app 路径、剩余风险。不要开始计划 02，等待下一条指令。
```

计划 01 验收通过后，在同一 Agent 中发送：

```text
计划 01 已验收。继续严格执行计划 02，并在完成门处停止汇报，不要提前进入计划 03。
```

后续对计划 03 和 04 使用相同方式逐阶段推进。分阶段停顿可以避免一个长任务在未验证基础上继续扩散错误。
