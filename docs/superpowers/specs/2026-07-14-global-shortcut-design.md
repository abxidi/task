# Task macOS 全局唤起快捷键设计

日期：2026-07-14
状态：用户已确认默认方式
范围：本机 Task 主窗口的全局唤起与自定义设置。

## 1. 行为

默认方式为在 `0.4` 秒内连续按下并释放两次 `Control`。两次按键之间出现任何其他按键输入时，本次序列失效。触发后应用取消隐藏、显示已有主窗口，并将其置为前台；不创建任务、不改变当前页面、不执行隐藏切换。

用户可在“设置 > 通用 > 唤起快捷键”选择：

1. 双击 `Control`。
2. 自定义组合键。
3. 停用。

常规组合键至少包含一个修饰键，使用 macOS 标准修饰符号显示。快捷键配置是本机非敏感偏好，存入 `UserDefaults`；不进入 SwiftData、JSON 备份、日志或网络请求。

## 2. 权限与失败处理

双击 `Control` 使用全局键盘事件监听，macOS 未授予输入监听权限时不得声称已生效。设置页展示非阻塞提示和“打开系统设置”操作。应用仍可正常打开、编辑和管理任务。

自定义组合键使用系统全局快捷键注册。若 macOS 报告系统保留或已被其他应用占用，保存前验证失败：当前已注册的快捷键继续生效，界面显示可恢复错误，偏好不被替换。

不拦截或吞掉任何键盘事件。双击检测只观察事件，确保 `Control` 仍能用于其他应用和系统行为。

## 3. 组件边界

- `GlobalShortcutConfiguration`：纯值类型，描述模式、键码与修饰键，负责默认值、编码和显示文本。
- `DoubleControlDetector`：纯状态机，接收时间戳、Control 按下/释放与其他按键事件，满足时间窗口时发出一次触发信号。
- `GlobalShortcutManager`：AppKit/Carbon bridge，注册普通组合键或安装全局监听；向应用层发布唤起事件与权限/注册状态。
- `ShortcutRecorderView`：仅负责设置页录入、自定义组合键显示、错误和辅助功能标签。
- `TaskApplication`：持有 manager 生命周期并接收唤起事件，使用 AppKit 激活已有主窗口。

领域层、SwiftData 模型、AI、通知与备份模块不依赖这些组件。

## 4. 测试与验收

- 纯配置测试：默认是双击 `Control`，自定义组合键编码后可恢复，停用状态不注册快捷键。
- 状态机测试：两个 `Control` 序列在 `0.4` 秒内触发；超时、夹杂其他键、单次按键均不触发。
- 注册测试：普通组合键注册失败时不替换当前配置；权限不可用时报告未生效状态。
- macOS 运行态验证：前台、后台和隐藏的 Task 均可被双击 `Control` 激活；未授权、冲突、深色模式和 VoiceOver 文案均可理解。
