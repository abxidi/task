## 1. 决策与覆盖范围

任务编辑采用“快速编辑 + Markdown 正文编辑”两层体验。本规格仅覆盖任务创建与编辑，并以用户在 2026-07-16 的确认覆盖此前文档中与本规格冲突的编辑器保存、关闭和正文编辑规则。

保留原有不可变领域结论：本机 SwiftData、`TaskItem`、`-3...3` 优先级、属性不抢占正文、无 AI 依赖。不会增加云同步、账号、富文本二进制存储或新的任务日期模型。

## 2. 用户流程

### 2.1 新建任务

1. 用户在看板列的加号处输入标题，按 `Control-Return` 创建任务。
2. 空白或仅空白字符不创建任务；成功创建后保留该列的快捷输入，方便连续添加。
3. 创建的任务使用当前列、默认 `(0, 0)` 优先级、无日期、无标签、未完成和空 Markdown 正文。
4. 用户点击卡片或从其他入口打开任务时，显示快速编辑弹窗。

### 2.2 快速编辑弹窗

弹窗置于半透明遮罩之上，初始高度紧凑；备注、子任务或已填属性增加时向下扩展，最大高度不超过窗口可用高度的 88%。

从上到下显示：

1. 标题前的紧凑优先级色块与象限名称。
2. 单行标题。
3. 正文摘要；空状态显示“添加备注...”。点击摘要进入 Markdown 正文编辑页。
4. 子任务区域和“创建子任务，Control-Return 提交”输入行。已创建项目可勾选、编辑、删除和拖拽排序。
5. 内联标签选择与创建入口。
6. 任务日期行。它只编辑既有的 `dueAt`；不把录屏中的“结束日期”伪造为可保存字段。

优先级、标题、子任务、标签、日期、完成状态和项目/看板列继续以 250 ms 防抖自动保存。新建弹窗在标题为空时不产生记录；已有任务标题被暂时清空时不删除原任务，关闭前提示恢复标题或取消关闭。关闭弹窗前必须同步 flush 尚未到期的属性保存。

### 2.3 Markdown 正文编辑页

点击快速弹窗的正文区域后，编辑器在同一主窗口中替换快速弹窗视图，呈现录屏中的沉浸式写作页：

- 顶部固定格式工具栏。
- 中间固定为左右等宽分栏：左侧编辑原始 Markdown，右侧实时预览。
- 底部显示“默认全屏”状态、字数统计、`Command-S` 保存、取消和确认按钮。
- 正文草稿仅存在内存中；打开期间不会触发自动保存。
- `Command-S` 和“确认”将 Markdown 一次写入 `TaskItem.details`，然后返回快速编辑弹窗。
- “取消”及 `Escape` 放弃本次正文草稿，返回快速编辑弹窗，保留打开编辑页之前的正文。

格式工具栏支持粗体、斜体、标题、有序/无序列表、任务列表、链接、图片、表格、引用、删除线和撤销/重做。工具栏命令作用于当前选择区，没有选择时插入成对标记并将插入点放在其中。所有按钮使用 SF Symbols、tooltip 和 VoiceOver 标签。

`details` 始终保存为 UTF-8 Markdown 文本。预览按相同 Markdown 文本实时渲染；无法解释的标记保留为原文，不能造成保存失败或数据丢失。

## 3. 组件边界

```text
TaskEditorOverlay
├── QuickTaskEditor
│   ├── QuickTaskHeader
│   ├── MarkdownSummaryRow
│   ├── SubtaskEditor
│   └── InlineTaskMetadata
└── MarkdownTaskEditor
    ├── MarkdownFormattingToolbar
    ├── MarkdownTextEditor (AppKit bridge for selection and undo)
    ├── MarkdownPreview
    └── MarkdownEditorFooter
```

`TaskEditorModel` 继续持有自动保存属性草稿。新增独立的 `MarkdownDraftSession`，只负责基准正文、可编辑正文、脏状态和显式提交/取消决策。它不得调用属性自动保存，也不得直接访问 SwiftData；写入仍经由 `TaskRepository`。

## 4. 错误与无障碍

- 自动保存失败时保留快速编辑内容并显示可恢复错误；关闭不会静默丢失属性。
- 正文保存失败时停留在 Markdown 编辑页并保留草稿、预览和选择状态。
- Reduce Motion 下快速弹窗与编辑页切换只淡入淡出；不使用缩放或飞入效果。
- 所有快捷键同时提供可发现的按钮和 VoiceOver 标签；分栏编辑和预览均可获得键盘焦点。

## 5. 验收条件

- 看板快捷输入只在有效标题的 `Control-Return` 后创建一个任务。
- 快速弹窗的元数据编辑自动保存，正文编辑期间不覆盖 `details`。
- Markdown 页的取消不改变 `details`；保存或 `Command-S` 只提交一次最终正文。
- 子任务、标签、日期与优先级在关闭快速弹窗前完成持久化。
- Markdown 编辑页有可用的格式命令、实时预览、字数统计、保存、取消和撤销/重做。
- 新建、编辑、取消正文编辑、保存正文编辑、自动保存失败和正文保存失败均有自动化测试。
