# 正在进行任务卡 46 / 54 分栏设计

日期：2026-08-25
状态：用户已确认，进入实施

## 目标

将“正在进行”任务卡中详情列与未完成子任务列之间的分隔线适度左移，使右侧长文本拥有更多阅读空间，同时保持左侧状态控件和备注编辑器可用。

## 已确认方案

- 采用 `46 / 54`，不采用 `38.2 / 61.8` 黄金分割。
- 比例只作用于任务卡的两列可用内容宽度；现有 `20 pt` 列间距、`Divider` 与卡片内边距不变。
- 双列状态下，左侧详情列至少 `276 pt` 宽，子任务列至少 `280 pt` 宽；当可用宽度低于约 `641 pt` 时，卡片改为上下堆叠，以免状态控件或子任务列溢出。
- 不变更任务、子任务、正在做状态、持久化数据、辅助功能标签或交互行为。

## 实现与验证

在 `FocusPoolPresentation` 中定义可测试的比例、双列下限和列宽计算；`FocusEntryColumnsLayout` 在同一次 SwiftUI 布局中接收父容器宽度，并将计算结果设置在左右列上。无界宽度提议使用有限的理想宽度回退；窄于双列下限时忽略分隔线并纵向堆叠两列，避免滚动容器的异步几何测量造成首帧零宽或内容溢出。单元测试覆盖 46 / 54 分配、最小双列宽度、窄宽度堆叠决策和无界宽度；随后执行完整构建、打包和签名验收。
