# Task macOS UI 设计规范

版本：1.0
状态：已批准
参考实现：`docs/ui/task-ui-reference.html`

## 1. 设计方向

Task 是一款安静、克制、信息密集的桌面生产力工具。界面应让用户在数小时连续使用后仍感到稳定，不采用营销式大标题、装饰性渐变、悬浮页面卡片或过度圆角。

视觉记忆点只有两个：

1. 固定为正方形的优先级坐标盘。
2. 用背景色表示紧急度、用色块内数字表示重要度的任务标记。

酸橙色用于焦点、选中和 AI 已启用状态，不作为大面积品牌底色。

## 2. 原生窗口

### 2.1 尺寸

| 项目 | 规格 |
| --- | ---: |
| 默认窗口 | `1280 × 820 pt` |
| 最小窗口 | `980 × 680 pt` |
| 标题栏 | 系统标题栏，内容参考高度 `40 pt` |
| 左侧导航 | 默认 `205 pt`，允许 `184...232 pt` |
| 右侧检查器 | 默认 `292 pt`，允许 `272...340 pt` |
| 主内容最小宽度 | `520 pt` |
| 内容页边距 | 水平 `24 pt`，垂直 `22 pt` |

使用 `NavigationSplitView` 表达侧栏、内容和检查器。窗口缩小时先隐藏检查器，再压缩侧栏；不得压缩四象限的宽高比。

### 2.2 窗口行为

- 主窗口使用系统 traffic-light controls 和工具栏材质。
- 任务编辑器使用 sheet；宽度 `760...900 pt`，最大高度为窗口可用高度的 88%。
- 任务设置在编辑器宽度至少 `820 pt` 时显示为右侧 inspector；较窄时显示为 popover。
- 删除、清空和覆盖导入使用系统 confirmation dialog。
- 所有 sheet 支持 `Escape` 取消，存在修改时先确认。

## 3. 视觉令牌

### 3.1 中性色

优先使用系统动态色。以下值用于 HTML 参考和 SwiftUI 浅色模式校准，不应替代 `Color(nsColor:)` 的动态能力。

| Token | 浅色参考 | SwiftUI 建议 | 用途 |
| --- | --- | --- | --- |
| `surface.canvas` | `#F7F7F3` | `windowBackgroundColor` | 主内容背景 |
| `surface.sidebar` | `#E9E9E4` | `underPageBackgroundColor` | 侧栏 |
| `surface.panel` | `#FBFBF8` | `controlBackgroundColor` | 检查器、sheet |
| `surface.raised` | `#FFFFFF` | `textBackgroundColor` | 输入区、任务卡片 |
| `text.primary` | `#20231F` | `labelColor` | 标题、主文案 |
| `text.secondary` | `#62665D` | `secondaryLabelColor` | 元数据 |
| `text.tertiary` | `#8A8D84` | `tertiaryLabelColor` | 提示、计数 |
| `line.default` | `#DADBD3` | `separatorColor` | 分隔线、边框 |
| `focus.acid` | `#D8FF5B` | 自定义动态色 | 焦点环、选中、AI 增强 |
| `danger` | `#D73D43` | `systemRed` | 最高紧急度、破坏操作 |

深色模式使用系统背景和文本色。优先级颜色保持语义不变，但必须在深色背景上保留 `2 pt` 的系统背景描边。

### 3.2 紧急度颜色

| 紧急度 | 背景色 | 文字色 | 用户语义 |
| ---: | --- | --- | --- |
| `-3` | `#354F9E` | `#FFFFFF` | 最可延后 |
| `-2` | `#438FC1` | `#FFFFFF` | 低紧急 |
| `-1` | `#68BEB0` | `#16312B` | 略低 |
| `0` | `#737970` | `#FFFFFF` | 未判断 / 中性 |
| `+1` | `#BAA94E` | `#302B14` | 略高 |
| `+2` | `#E38A39` | `#3A220A` | 高紧急 |
| `+3` | `#D73D43` | `#FFFFFF` | 最高紧急 |

每个值必须使用独立颜色，不允许把多个值合并成同一色阶。

### 3.3 项目颜色

项目颜色与优先级颜色承担不同职责。默认项目色板为：

```text
珊瑚 #F07446
翠绿 #269276
钴蓝 #4778D9
洋红 #C85D8C
紫灰 #7B6FA8
石墨 #555B54
```

项目色只用于小圆点、筛选标记和窄边线，不用于任务优先级色块。

### 3.4 字体

| 用途 | SwiftUI | 参考尺寸 |
| --- | --- | ---: |
| 页面主标题 | `.system(size: 26, weight: .semibold, design: .serif)` | `26 pt` |
| Sheet 任务标题 | `.system(size: 30, weight: .semibold, design: .serif)` | `30 pt` |
| 区域标题 | `.headline` | `13 pt` |
| 正文 | `.body` | `13 pt` |
| 紧凑控件 | `.callout` | `12 pt` |
| 元数据 | `.caption` | `10–11 pt` |
| 任务标记数字 | `.system(size: 10, weight: .bold, design: .rounded)` | `10 pt` |

正文使用系统 San Francisco；页面和任务标题使用系统 New York serif 设计。不得下载或嵌入第三方字体。

### 3.5 间距与圆角

- 基础间距单位：`4 pt`。
- 常用间距：`4 / 8 / 12 / 16 / 20 / 24 / 32 pt`。
- 小控件圆角：`5 pt`。
- 任务卡片和面板圆角：`6 pt`。
- Sheet 圆角由系统控制。
- 禁止在卡片中嵌套装饰性卡片；只对任务、指标单元和输入工具使用边界。

### 3.6 应用图标

- 画布：`1024 × 1024 px`，由系统裁切圆角，源文件不预切圆角蒙版。
- 背景：石墨黑 `#20231F`，纯色，无渐变和纹理。
- 主图形：酸橙色 `#D8FF5B` 的任务清单标记，由三个方形节点、两条水平任务线和一个勾选笔画组成。
- 安全边距：四边至少 `160 px`。
- 小尺寸优先：在 `16 px` 下必须仍能识别节点与勾选，不使用文字或细描边。
- 图标不得使用优先级 7 级颜色，以免与任务语义混淆。

## 4. 优先级地图

### 4.1 几何规则

- 坐标范围：紧急度和重要度均为整数 `-3...3`。
- 共 49 个离散坐标。
- 坐标网格保持 `1:1`，边长取页面剩余可用宽高的较小值，最大 `620 pt`；主页面不得因地图出现纵向滚动条。
- 绘图区四边内缩 `24 pt`，避免边界任务点被裁切。
- 四个象限标签位于坐标网格外侧：上方依次为“重点规划”“立即处理”，下方依次为“稍后处理”“适当委派”。
- 7 条横线和 7 条纵线分别对应 `-3...3`。
- 中心轴线宽 `1 pt`，其他网格线宽 `0.5 pt`。

坐标转视图位置：

```swift
let plot = size.insetBy(dx: 24, dy: 24)
let x = plot.minX + CGFloat(urgency + 3) / 6 * plot.width
let y = plot.maxY - CGFloat(importance + 3) / 6 * plot.height
```

拖拽转坐标：

```swift
let normalizedX = ((location.x - plot.minX) / plot.width).clamped(to: 0...1)
let normalizedY = ((plot.maxY - location.y) / plot.height).clamped(to: 0...1)
let urgency = Int((normalizedX * 6).rounded()) - 3
let importance = Int((normalizedY * 6).rounded()) - 3
```

### 4.2 象限与零轴

| 区域 | 条件 | 标签 |
| --- | --- | --- |
| 右上 | `x > 0 && y > 0` | 立即处理 |
| 左上 | `x < 0 && y > 0` | 重点规划 |
| 右下 | `x > 0 && y < 0` | 适当委派 |
| 左下 | `x < 0 && y < 0` | 稍后处理 |
| 坐标轴 | `x == 0 || y == 0` | 待判断 |

“待判断”不增加第五块背景，只在筛选和统计中作为独立类别。

### 4.3 任务标记

| 状态 | 尺寸与样式 |
| --- | --- |
| 默认 | `24 × 24 pt` 圆角色块，圆角 `7 pt`，`2 pt` 背景描边 |
| Hover | 放大到 `26 × 26 pt`，显示任务名称与完整坐标 tooltip |
| 选中 | 外加 `3 pt` 酸橙色焦点环，显示持久标签 |
| 键盘焦点 | 系统焦点环 + VoiceOver 标签 |
| 拖动 | `28 × 28 pt`，显示十字参考线和实时坐标 |
| 同格堆叠 | 两项及以上显示叠层色块与数量徽标，点击后展开任务列表 |

色块背景按紧急度取色；内部显示重要度 `-3...+3`，正数带 `+`。示例：红色 `+3` 表示 `紧急度 +3 / 重要度 +3`。

### 4.4 交互

- 单击选择。
- 双击或 `Return` 打开任务编辑器。
- 拖动时连续显示位置，松手吸附并保存。
- 方向键按一个格点移动。
- `Space` 打开 Quick Look 风格预览。
- 同格任务数达到 2 时点击堆叠展开 popover。

动画时长 `140–180 ms`，使用系统 ease-out。启用“减少动态效果”时取消缩放，仅保留颜色和焦点变化。

## 5. 应用壳层

### 5.1 左侧导航

顺序固定：

1. 优先级地图。
2. 任务列表。
3. 项目看板。
4. 数据洞察。
5. 快捷筛选：今天、未来 7 天、全部任务。
6. 项目列表。
7. 本机工作区和设置。

导航行高度 `34 pt`。选中行使用石墨背景和白色文字，图标使用酸橙色。使用 SF Symbols：

```text
优先级地图: square.grid.3x3
任务列表: checkmark.circle
项目看板: rectangle.3.group
数据洞察: chart.xyaxis.line
今天: sun.max
未来 7 天: calendar
全部任务: checklist
设置: gearshape
```

### 5.2 页面标题区

- 第一行是日期、项目或筛选上下文，使用 tertiary text。
- 第二行是 serif 页面标题。
- 右侧只放当前页面的主要动作和最多两个辅助动作。
- 主要动作优先使用图标 + 文本；纯图标按钮必须有 tooltip。

### 5.3 全局唤起快捷键

“设置 > 通用”顶部增加“唤起快捷键”区，使用原生 `Form` 行，不新增独立设置页或装饰性卡片。

- 默认值显示为“连按两次 Control”。辅助文字为“0.4 秒内完成；仅显示并激活 Task 主窗口”。
- 方式使用分段控件：`双击 Control`、`自定义组合键`、`停用`。
- 选择“自定义组合键”后显示一行可聚焦的快捷键录入控件，录入成功后以 macOS 标准符号显示组合键。
- 选择“双击 Control”但未获得输入监听权限时，行内显示黄色系统警告图标、原因文字和“打开系统设置”按钮；不使用阻塞弹窗。
- 自定义组合键无法注册时，录入控件显示错误状态与“该组合键不可用”；此前正在生效的快捷键保持不变。
- 所有快捷键控件均有 VoiceOver 标签，说明当前方式、已录入组合键、权限状态和是否已生效。

## 6. 任务编辑器

### 6.1 默认态

视觉顺序：

1. 大号任务标题输入。
2. 任务描述编辑器，最小高度 `160 pt`。
3. 子任务列表。
4. “添加子任务”输入行。

主区不直接展示日期、项目、标签或优先级。标题为空时保存按钮禁用；其他字段均可使用默认值。

### 6.2 子任务

- 行高至少 `36 pt`。
- 左侧 `14 pt` checkbox，右侧仅在 hover 时显示拖拽手柄和删除菜单。
- `Return` 保存当前行并创建下一行。
- 空白新行再次按 `Return` 结束连续创建。
- 完成子任务使用轻微弱化和删除线，不立即隐藏。

### 6.3 任务设置

顶部工具栏使用 `slider.horizontal.3` 图标和“任务设置”文字。

设置顺序必须为：

1. 正方形优先级地图。
2. 日期与提醒。
3. 预计时长。
4. 项目和看板列。
5. 完成状态。
6. 标签。

优先级地图在 inspector 中占满可用宽度，仍保持正方形。其余属性使用原生 `Form` 行，不用大卡片。

## 7. 项目看板与指标

### 7.1 指标带

顶部指标使用单个连续容器，以分隔线分成四格，不使用四张浮动卡片：

- 完成率。
- 高重要任务。
- 计划负载。
- 计划健康度。

每格最小宽度 `130 pt`，高度 `62 pt`。健康度必须附带可打开的扣分说明。

### 7.2 图表

- 完成趋势使用原生 Swift Charts 柱状图。
- 象限分布使用扇形图或环图，并同时提供文字图例。
- 图表颜色使用四象限语义色，不复用紧急度 7 级色作为数据系列。
- 图表为空时显示简洁空状态，不伪造数据。

### 7.3 看板

- 默认四列：待规划、本周计划、进行中、已完成。
- 列宽 `220...280 pt`，横向滚动。
- 任务卡片圆角 `6 pt`，内边距 `10 pt`。
- 卡片右上显示 `24 pt` 优先级角标，内缩 `10 pt`；左侧保留完成勾选与两行以内标题，标题需为角标预留空间。
- 日期和预计时长位于底部元数据行。
- 拖动目标列使用 `2 pt` 酸橙色内描边，不改变列宽。

## 8. AI 状态

### 8.1 未配置

- 不显示 AI 侧栏、星光图标或“配置 AI”宣传卡。
- 主内容自然占据右侧空间。
- 设置页可以显示独立的“AI 服务”配置区域。

### 8.2 已配置

- 工具栏出现“AI 规划本周”。
- 右侧检查器可切换为 AI 规划助手。
- AI 状态使用小面积酸橙色和 `sparkles` SF Symbol。
- 风险提示按严重度使用系统红、橙、黄，不使用大面积彩色背景。
- “审阅变更”是唯一能进入应用流程的主按钮。

### 8.3 变更审阅

每项建议显示：

- 任务名称。
- 修改字段。
- 修改前值。
- 建议值。
- 接受 checkbox。

默认全部不选中。用户确认后一次应用；失败时保留审阅列表和用户选择。

## 9. 空、错、载入状态

| 场景 | 行为 |
| --- | --- |
| 无任务 | 地图中心显示简洁“新建任务”按钮，不展示功能介绍 |
| 筛选无结果 | 显示“清除筛选”，保留当前视图结构 |
| 数据库错误 | 使用阻塞恢复页，提供重试和诊断导出 |
| AI 请求中 | 右侧检查器显示进度和取消按钮，主任务功能可继续使用 |
| AI 失败 | 在检查器内显示可重试错误，不关闭已有草案 |
| 通知未授权 | 仅在设置行显示状态和系统设置按钮 |
| 导入校验失败 | 显示逐项错误，不写入任何数据 |

## 10. 可访问性

- 所有交互目标最小 `24 × 24 pt`；高频按钮优先 `28 × 28 pt`。
- 任务点 VoiceOver 文本：“任务名，紧急度正 3，重要度正 3，立即处理”。
- 地图提供按 Tab 进入、方向键移动和 `Return` 打开。
- Tooltip 不能是理解任务点的唯一方式。
- 所有文字与背景至少满足 WCAG AA；优先级色块文字色按本规范固定。
- 支持 Increase Contrast、Reduce Motion 和系统深色模式。
- 图表提供可访问性摘要和逐数据点描述。

## 12. 视觉验收清单

- [ ] 默认窗口与最小窗口无重叠或截断。
- [ ] 四象限在所有尺寸下保持 `1:1`。
- [ ] 地图显示 7 个横纵刻度，不出现 `-5`、`+5` 或 11 级图例。
- [ ] `(+3,+3)` 使用警示红背景并在内部显示 `+3`。
- [ ] 任务编辑首屏只突出标题、描述和子任务。
- [ ] 任务设置中的优先级地图位于其他属性上方。
- [ ] 未配置 AI 时不保留空侧栏。
- [ ] 看板指标使用连续指标带，不堆叠装饰卡片。
- [ ] 所有纯图标按钮有 tooltip 和 accessibility label。
- [ ] 浅色、深色、Increase Contrast 和 Reduce Motion 状态均可用。
